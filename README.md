# Social Downloader API

Routes

`/facebook?url={url-videdo}`

url-video: Link of the video (Allows reels)

```
Example:
/facebook?url=https://www.facebook.com/reel/522368103351148
```

---

`/youtube?url={url-videdo}`

url-video: Link of the video (Allows shorts)

```
Example:
/youtube?url=https://www.youtube.com/watch?v=QNYT9wVwQ8A
```
